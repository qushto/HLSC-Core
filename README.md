# HLSC-Core
Серверное ядро для МКБЕ с версии 1.20.0 - до последней (мультиверсия), стараюсь довести ядро до ванильного состояния.
Реализованы все мобы 1.20.0,
Кастомная генерация,
Босы,
Блоки,
Механики,
И весь остальной контент будет делаться со временем, ядро в активной разработке 1-им человеком.
Оффицальный телеграмм канал ядра, там обновления выходят чаще всех жду - https://t.me/HeliosCore ,
Ядро разрабатывается на PHP 8.4,
Имеется мобильное приложение.
